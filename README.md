# Employee Scheduling System

A web-based employee scheduling platform built with React, TailwindCSS, and Docker.

## Features
- Dashboard
- Employee management
- Shift scheduling
- Calendar planner
- Vacation and shift request system

## Tech Stack

Frontend:
- React
- Vite
- TailwindCSS

Backend:
- Node.js (planned)

Infrastructure:
- Docker
- Oracle Cloud VPS

## Project Structure

employee-scheduler
│
├ frontend (React app)
├ backend (API server)
└ docker-compose.yml

## Future Features

- Drag-and-drop scheduler
- Employee availability tracking
- Shift swapping
- Role-based access
- Notification system
